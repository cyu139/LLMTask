	Fuzzy Logic is a computing approach for calculating “degrees of truth” rather than strict true/false values for use in binary logic. Most machine learning models are trained on data that’s extremely black and white. For example, we could have data on someone called Brian who has entries in height as 5’9 and hair color as brown. If we were to translate that data into binary values, Height: Tall might be marked as 1 (Height: Short would be 0), and Hair: Black might be 1 while Hair: Blonde might be 0 (this is assuming there is no Hair: Brown category). This is not a very accurate representation of Brian, as 5’9 could be considered short for a male individual in some cultures, and Brian definitely doesn’t have Black hair. However, the system needs to put his features in clear sets in order to calculate logic correctly. The solution to this is fuzzy logic, where the sets themselves start becoming fuzzy and truth values are not dictated by raw 0s and 1s. Brian’s data in this case might have Height: Tall as 0.6 and Height: Short as 0.4, along with Hair: Black as 0.7 and Hair: Blonde as 0.3.

	What we did is called fuzzification, and it’s the first step out of 4 in the Fuzzy Logic method. Fuzzification is where raw input data is translated into fuzzy sets and degrees of truths. Let’s work with another example: raining. We could have data sets where rain is 1 and no rain is 0, but when we want to classify light sprinkling, would we say 1 or 0 for that? If we were to fuzzify this data we could then interpret light sprinkling as maybe 0.3 on the rain scale, and 0.7 on the no rain scale.
    
	The next step is called rule evaluation, where we want to apply the fuzzy rules (such as If A, then B), to obtain outputs. For example, if we were to apply the rule “If raining, then it is overcast” we would then obtain a value for how overcast it is after applying that function. We would do this over many inputs in order to get a nice sense of the graph for how overcast it is over, say, a city.

	The third step is aggregation, where the output sets are combined and the maximum of their membership functions are taken. Other methods can include taking the sum of membership functions and then capping it at 1 or renormalizing the sum so that the max value is 1.

	The final step is defuzzification and this is done so that there is a final, “crisp” estimate of the value.     Performing these steps outputs a result that mimics how humans perform reasoning when given information. Humans don’t think in black and white, and neither should the logic performed by programs if the program is expected to start thinking like a human. When we look at a throne and asked if whether or not that throne is a chair, we usually consider all aspects of what makes it a chair (or not) and come to a conclusion, but we don’t forget the little nuances that are there - we don’t forget the features that make it a throne and would put that into consideration when asked to use it logically in some way for another question. That should be the same when we are trying to have machines calculate logical inferences when given fuzzy data, and by doing this we will get closer to human-like evaluation in machines.
